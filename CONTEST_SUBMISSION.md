# Freelancer Contest Entry

## Title

Linear Guard — Governed Linear Integration

## Description

I built Linear Guard as a signed RailCall module for real Linear workspaces. It includes ten useful commands covering user, team, project, label and workflow discovery; issue search and retrieval; plus issue creation, updates and comments.

The three write commands are not allowed to run silently. RailCall first previews the exact payload, blocks it until a human approves it, executes only the approved action and records the result in a signed receipt that can be verified independently.

I tested the module against the real Linear GraphQL API. The evidence shows an unapproved write being blocked without touching Linear, followed by approved issue creation, title and priority updates, and a governed comment appearing in the Linear activity feed.
